# Projet des arbres de St Quentin - Partie-Web

## Site : 
http://jpelle27.projets.isen-ouest.info/Projet---Partie-Web/Front/

## Description

Ce projet est une application web permettant de visualiser, gérer et analyser des arbres à l’échelle d’un territoire via une interface cartographique interactive.

L’objectif est de fournir un outil complet pour :

* la **visualisation géographique des arbres**
* la **gestion des données**
* l’**analyse spatiale (clusters)**
* la **prévision de l’état de santé et des risques**

---

## Fonctionnalités

### Visualisation

* Affichage des arbres sur une carte interactive
* Localisation précise via coordonnées GPS
* Interface fluide avec zoom et navigation
* Affichage des données individuelles des arbres
* Limite imposé pour éviter de dépenser trop de ressources

### Gestion des arbres

* Ajout de nouveaux arbres dans la base de données
* Stockage des informations :
  * espèce
  * âge
  * hauteur
  * localisation
  * état
  * etc...

### Estimation de l’âge

* Calcul ou estimation de l’âge d’un arbre à partir de ses caractéristiques

### Prédiction des risques

* Analyse de la probabilité de déracinement

---

## Technologies utilisées

### Frontend

* HTML / CSS / JavaScript / PHP

### Backend

* JS ou Python

### Base de données
